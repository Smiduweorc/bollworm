# Development

Go 1.27.3 and npm (for lefthook, commitlint and git-cliff, installed by
`make setup`). `make lint` also needs golangci-lint (CI pins v2.15.0) and
shellcheck on the `PATH`; on Arch, `pacman -S golangci-lint shellcheck`.
`make validate` needs `curl` and `xmllint`.

`make help` lists the other targets.

Commits follow Conventional Commits (`fix(render): ...`), checked by
commitlint in the `commit-msg` hook. `CHANGELOG.md` is generated by
git-cliff; do not edit it by hand.

The `.docx` is written with Go's standard library. The dependencies are a
YAML parser, a CommonMark parser, the command-line library, Google's protobuf
runtime and its `google.api` annotations, and bufbuild's protocompile, all
MIT, BSD or Apache licensed.

## Releasing

`make release V=v0.1.0` (or `V=patch|minor|major`) tags the release locally
and pushes nothing unless `PUSH=1`. Pushing the tag runs GoReleaser, which
publishes the binaries and packages to the GitHub release.

The AUR is not updated by GoReleaser. Bump `pkgver` in the `PKGBUILD`, run
`updpkgsums` and `makepkg --printsrcinfo > .SRCINFO`, commit both here, and
copy them to the AUR clone.
